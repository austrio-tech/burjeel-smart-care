## 🎨 Customization Guide

### Change Primary Color
Edit `tailwind.config.js`:
```javascript
colors: {
  primary: { 600: '#your-color' }
}
```

### Change API URL
Edit `.env.local`:
```
VITE_API_BASE_URL=https://your-api.com
```

### Add New Page
1. Create: `src/pages/NewPage.jsx`
2. Import in: `src/App.jsx`
3. Add route: `<Route path="..." element={...} />`

### Add New Component
1. Create: `src/components/common/NewComponent.jsx`
2. Use: `import NewComponent from '...'`

## 🐛 Quick Troubleshooting

| Issue | Solution |
|-------|----------|
| Port in use | `npm run dev -- --port 3000` |
| Module not found | `rm -rf node_modules && npm install` |
| API failing | Check backend running & VITE_API_BASE_URL |
| WebSocket not connecting | Verify VITE_WS_URL & backend WS server |
| Build error | Clear cache: `rm -rf dist && npm run build` |
